# Withdrawn requirements

These ids are not declared by any capability specification, so they carry no
`Source:` trace and the policy checker requires no coverage-ledger evidence for
them. The list is here so that a reader who meets one in an archived design or contract document can see
what happened to it rather than re-add it.

| Id       | Was                                                                                   | Outcome                                                                                           |
| -------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `FR-012` | The artboard's switching script hides the plate container for every mode but `mounts` | **Withdrawn** in wave 13: the `POWER` mode replaces the plates, so no mount carries a power state |
